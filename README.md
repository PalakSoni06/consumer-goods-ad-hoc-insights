# AtliQ Consumer Goods - Ad Hoc Insights

## 📊 Project Overview
This project is based on a SQL challenge conducted by AtliQ Hardwares to analyze business data and generate meaningful insights for decision-making.

## 🎯 Problem Statement
The management lacked sufficient insights to make quick, data-driven decisions. This project focuses on solving that gap using data analytics.

## 🛠 Task Performed
- Solved 10 ad-hoc business requests using SQL  
- Analyzed sales, customers, products, and channels  
- Created a Power BI dashboard and presentation for top-level management  

## 🧰 Tools Used
- SQL (MySQL)  
- Power BI  

## 📈 Key Insights
- Identified top-performing products and divisions  
- Analyzed monthly and quarterly sales trends  
- Found channel contribution to overall sales  
- Highlighted impact of external factors like COVID-19  

## 🚀 Conclusion
This project demonstrates the ability to use SQL and Power BI to solve real-world business problems and present insights effectively.
